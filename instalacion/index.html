Instalación de Angular

Guía completa de instalación paso a paso

Pasos de Instalación

1

Instalar Node.js y npm

Node.js es necesario para ejecutar npm y angular-cli. Descargar desde nodejs.org

Versiones requeridas: Node.js v20 LTS o superior, npm v10 o superior
2

Instalar Angular CLI globalmente

Angular CLI es la herramienta oficial de línea de comandos para Angular

npm install -g @angular/cli
3

Crear un nuevo proyecto Angular

Usar el comando ng new para crear una nueva aplicación

ng new nombre-proyecto
4

Navegar al proyecto y ejecutarlo

Entrar en el directorio del proyecto e iniciar el servidor de desarrollo

cd nombre-proyecto && ng serve

Requisitos del Sistema

✓Node.js v20.0.0 o superior
✓npm v10.0.0 o superior (incluido con Node.js)
✓Angular CLI 21.x
✓TypeScript 5.9 o superior (instalado automáticamente)
✓Editor de código (VS Code recomendado)
✓200MB de espacio en disco (aproximadamente)

Variables de Entorno

NODE_PATH

Ruta al directorio de módulos de Node.js (opcional)

PATH

Debe incluir el directorio bin de Node.js

Notas importantes

  • Angular no requiere base de datos para la instalación. La base de datos se configura según las necesidades del proyecto.
  • Angular CLI crea una estructura de proyecto con todas las configuraciones necesarias.
  • El servidor de desarrollo está disponible en http://localhost:4200
  • Los cambios en el código se reflejan automáticamente en el navegador (hot reload).
