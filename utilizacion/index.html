¿Cómo visualizar los resultados?

1

Iniciar servidor de desarrollo

ng serve
Resultado: La app está disponible en http://localhost:4200
2

Editar archivos

Modificar .ts, .html, .scss
Resultado: Los cambios se reflejan automáticamente en el navegador
3

Abrir el navegador

Ir a http://localhost:4200
Resultado: Ver la aplicación en ejecución
4

Inspeccionar con DevTools

F12 en el navegador
Resultado: Acceder a herramientas de desarrollo para debugging

Características del servidor de desarrollo

  • Hot Module Replacement (HMR): Los cambios se ven en tiempo real
  • Source Maps: Facilita el debugging del código TypeScript
  • Compilación automática: Detecta y compila cambios automáticamente
  • Live Reload: Recarga automática del navegador cuando es necesario
  • CORS habilitado: Facilita integración con APIs externas
