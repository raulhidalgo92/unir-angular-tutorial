Conceptos clave y arquitectura de Angular

¿Sobre qué actúa Angular?

Angular actúa sobre componentes, que son bloques de código que contienen elementos HTML (vistas), lógica TypeScript (componente) y estilos CSS/SCSS. Estos componentes se pueden reutilizar y combinar para crear aplicaciones web complejas.

Componentes

Unidades reutilizables que encapsulan HTML, CSS y lógica TypeScript. Cada componente es responsable de una parte de la interfaz.

@Component({ selector: "app-nombre", ... })

Directivas

Instrucciones que modifican el comportamiento o la apariencia de elementos del DOM. Las más comunes son *ngIf, *ngFor, [ngClass].

<div *ngIf="mostrar">Contenido</div>

Servicios

Clases que contienen lógica compartida entre componentes. Se inyectan donde se necesitan mediante inyección de dependencias.

@Injectable({ providedIn: "root" })

Rutas

Sistema de enrutamiento que permite navegar entre diferentes componentes sin recargar la página.

const routes: Routes = [{ path: "inicio", component: InicioComponent }]

¿Cómo se referencian los archivos?

En Angular, los archivos se referencian a través de distintos mecanismos de vinculación de datos y componentes. Los más importantes son:

Método
Sintaxis
Uso
Interpolación
{{ variableDelComponente }}
Mostrar valores dinámicos en el template
Property Binding
[propiedad]="valor"
Vincular propiedades HTML a variables TypeScript
Event Binding
(evento)="metodo()"
Responder a eventos del usuario
Two-Way Binding
[(ngModel)]="variable"
Sincronizar datos bidireccionales entre template y componente
Selector de componente
<app-nombre></app-nombre>
Incrustar componentes dentro de otros componentes

Ciclo de vida de los componentes

Hooks principales:

  • ngOnInit: Se ejecuta cuando el componente se inicializa
  • ngOnChanges: Se ejecuta cuando cambian las propiedades de entrada
  • ngAfterViewInit: Se ejecuta después de renderizar la vista
  • ngOnDestroy: Se ejecuta cuando el componente se destruye
