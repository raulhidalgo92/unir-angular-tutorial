Primeros Pasos

Tu primer "Hola Mundo" en Angular

¿Cómo crear tu primer componente?

Un componente "Hola Mundo" es la forma más simple de empezar con Angular. Consiste en una clase con un decorador @Component que define la lógica y una plantilla que muestra un mensaje en el navegador. Es el primer paso para entender cómo funcionan los componentes en Angular.

Código ejemplo

import { Component } from '@angular/core';

@Component({
  selector: 'app-hello',
  standalone: true,
  template: '<h1>{{ message }}</h1>'
})
export class HelloComponent {
  message = 'Hola Mundo desde Angular';
}

Pasos para hacerlo funcionar

1

1. Crear un componente

En Angular, todo gira alrededor de componentes. Es la unidad básica de una aplicación Angular.

2

2. Definir el template

El template HTML contiene la vista del componente con interpolación de datos y directivas.

3

3. Añadir lógica TypeScript

La clase del componente contiene la lógica, propiedades y métodos de la aplicación.

4

4. Inyectar en el módulo/app

Incluir el componente en las importaciones de la aplicación principal.

5

5. Ver en el navegador

El componente se renderiza en el navegador cuando accedes a la ruta correspondiente.

Resultado esperado

Hola Mundo desde Angular

Este es el resultado que verás en tu navegador al ejecutar el código anterior.
