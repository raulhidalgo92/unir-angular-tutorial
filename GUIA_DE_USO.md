# 🚀 GUÍA DE USO - TUTORIAL ANGULAR

## 🎯 Acceso a la Aplicación

### En Tu Máquina Local

1. **Abre terminal/PowerShell**
2. **Navega a la carpeta del proyecto**
   ```
   cd c:\Users\raulh\Workspace\UNIR\angular-tutorial
   ```

3. **Inicia el servidor**
   ```
   ng serve
   ```

4. **Abre tu navegador**
   ```
   http://localhost:4200
   (o el puerto que aparezca en la terminal)
   ```

## 🚨 Si Algo No Funciona

### El servidor no inicia
```
❌ Error: "Command not available outside workspace"
✅ Solución: 
   cd c:\Users\raulh\Workspace\UNIR\angular-tutorial
   ng serve

❌ Puerto 4200 ocupado
✅ Solución: El servidor elige otro puerto automáticamente
   (verifica en la terminal cuál es)
```

### Cambios no se ven
```
❌ Página no actualiza
✅ Solución:
   • Espera unos segundos (está compilando)
   • Recarga manualmente (F5 o Ctrl+R)
   • Limpia caché (Ctrl+Shift+R)
```

### Estilos se ven raros
```
❌ Colores o fuentes incorrectos
✅ Solución:
   • Abre DevTools (F12)
   • Verifica no haya CSS de navegador conflictivo
   • Limpia caché del navegador
```
