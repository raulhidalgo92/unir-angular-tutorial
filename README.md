Proyecto educativo completo sobre Angular desarrollado para la asignatura de UNIR. Este tutorial cubre desde la instalación hasta conceptos avanzados del framework.

## Descripción del Proyecto

Aplicación web educativa que funciona como un tutorial interactivo de Angular, incluyendo:

- **Justificación**: Por qué usar Angular en proyectos modernos
- **Instalación**: Guía paso a paso del entorno de desarrollo
- **Primeros Pasos**: Tu primer componente "Hola Mundo"
- **Utilización**: Cómo crear y ejecutar aplicaciones
- **Funcionamiento**: Arquitectura interna de Angular
- **Conclusiones**: Resumen y próximos pasos

## Stack Tecnológico

- Angular 21.0.1
- TypeScript 5.9+
- SCSS (Sass)
- Node.js 25.2.1

## Instalación

1. Clona el repositorio:
```bash
git clone [url-del-repositorio]
cd angular-tutorial
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
ng serve
```

4. Abre tu navegador en `http://localhost:4200/`

## Comandos Útiles

### Desarrollo
```bash
ng serve                    # Servidor de desarrollo
ng serve --port 4200       # Servidor en puerto específico
```

### Build
```bash
ng build                    # Build de producción
ng build --configuration production
```

### Testing
```bash
ng test                     # Tests unitarios
```

### Generación de componentes
```bash
ng generate component nombre-componente
ng generate service nombre-servicio
```
