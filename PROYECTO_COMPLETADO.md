## 🚀 Cómo Ejecutar

```bash
# 1. Asegúrate de estar en la carpeta correcta
cd c:\Users\raulh\Workspace\UNIR\angular-tutorial

# 2. Instala dependencias (si es necesario)

# 3. Inicia el servidor de desarrollo

# 4. Abre en tu navegador (por defecto http://localhost:4200)
```

- ✅ Hot reload automático

- ✅ Compilación eficiente
